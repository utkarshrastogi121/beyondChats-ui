# beyondChats‑UI 

A **React + TypeScript + Vite UI** for the **BeyondChats Blog Enhancer** — a tool that automatically updates the latest BeyondChats blog articles using insights from top-ranking articles on Google.

This frontend allows users to view and interact with blog updates generated by an LLM after fetching and comparing content from external sources.
Initially, it will take few minutes to load the scraped data.

---

## 📌 Features

- 🔍 Fetches the **latest 5 blogs** from [BeyondChats](https://beyondchats.com/blogs/) via a web scraper
- 🌐 Searches each blog title on **Google** and fetches the **top 2 relevant articles**
- ✍️ Scrapes main content from the top 2 Google articles
- 🤖 Calls an **GROQ API** to update the original blog, making its formatting and content align with top-ranking articles
- ⚛️ Built with **React + TypeScript + Vite**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/utkarshrastogi121/beyondChats-ui.git
cd beyondChats-ui
```
### 2. Install dependencies

```bash
npm install
```
### 3. Start the development server
```bash
npm run dev
```
